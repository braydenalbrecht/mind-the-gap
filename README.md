# Mind the Gap

A private, auto-generated daily CS briefing podcast for one listener's commute. Episodes are written each weekday morning, turned into audio with GitHub Actions, and published as a podcast feed on GitHub Pages.

Feed: https://braydenalbrecht.github.io/mind-the-gap/feed.xml

See `RUNBOOK.md` for how an episode gets made and `config/show.md` for the show's settings.
